# Contributing to NOX AI

Thank you for your interest in contributing to NOX AI! This document outlines guidelines and best practices to help you get started.

## Development Workflow

1. **Fork & Clone** the repository
2. **Install dependencies**: `npm install`
3. **Start development server**: `npm run dev`
4. **Run build check**: `npm run build`

## Code Style

- Write clean, type-safe TypeScript.
- Follow ESLint configurations (`npm run lint`).
- Maintain accessibility standards on all UI components.

## Commit Conventions

We follow Conventional Commits:
- `feat:` for new capabilities
- `fix:` for bug fixes
- `refactor:` for code restructurings
- `docs:` for documentation updates
- `perf:` for performance optimizations
